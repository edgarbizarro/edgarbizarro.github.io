O caminho de uma requisição

Cada projeto vive em uma camada. Role e acompanhe.

1 de 5 · Cliente

Interface

A requisição nasce numa tela. Componentes em React e TypeScript conversam com o back-end por Inertia, com estado, validação e gráficos que precisam ser claros para quem usa.

fin_control ↗ Gestão financeira pessoal: dashboard de receitas e despesas, orçamentos mensais por categoria e relatórios. Laravel 12 · React 19 · TypeScript · Inertia · Tailwind

2 de 5 · Servidor

Rota e autenticação

Antes de qualquer regra, a API confirma quem está chamando. Login, token JWT, senhas com hash e rotas protegidas, em uma arquitetura hexagonal que separa o framework do domínio.

rust_api ↗ API REST de usuários com autenticação JWT, migrações e Docker, escrita em Rust. Rust · Axum · SQLx · SQLite · Docker

3 de 5 · Domínio

Regras de negócio

É aqui que o sistema decide o que é permitido: uma campanha ativa por cluster, SKU único, desconto nunca negativo. Regras explícitas, em camadas separadas, para que mudar uma não quebre as outras.

spagc ↗ API de promoções regionais: estados, cidades, clusters, campanhas, descontos e produtos. Laravel 10 · MySQL · Docker (Sail) · OpenAPI

4 de 5 · Persistência

Banco de dados

Dinheiro não pode ficar pela metade. Transferências, depósitos e estornos acontecem como operações atômicas: ou tudo é gravado, ou nada é.

walletw ↗ API de carteira digital com cadastro, autenticação, transferências entre usuários, estorno e histórico. Laravel 12 · MySQL · Sanctum · Docker (Sail)

5 de 5 · Resposta

Resposta e confiança

A resposta volta com o status certo, documentada em OpenAPI e coberta por testes unitários e de ponta a ponta. Quem consome a API sabe o que esperar, e quem mantém sabe o que quebrou.

Todos os repositórios ↗ Código, testes e documentação no GitHub. PHPUnit · Playwright · OpenAPI · Docker
